Tokenisation données réelles

Blocs Transformer schéma animé

Le cœur du modèle : — blocs empilés. Chaque bloc contient une couche d'attention (les tokens « se parlent ») et un MLP (transformation locale de chaque token). Les connexions résiduelles et la normalisation stabilisent l'apprentissage.

La matrice d'attention ci-dessous est un schéma pédagogique (masque causal + proximité) — les vraies cartes d'attention arrivent en Phase 3.

Probabilités du prochain token logprobs Ollama

Après tous les blocs, une couche linéaire produit un score (logit) pour chaque token du vocabulaire. Le softmax les transforme en probabilités. Le modèle en choisit un — c'est la prédiction du prochain token.

Ajustez la température, le top-k et le top-p pour voir comment le tirage change (recalcul côté navigateur sur les logprobs retournés).
